# UI Management Interface Introduction

Welcome to the Plandex UI Management Interface! This interface provides a user-friendly way to manage various aspects of your Plandex instance, from configuring Large Language Models (LLMs) to interacting with project files and executing commands.

## Accessing the Interface

The UI Management Interface is a web-based application typically served alongside your Plandex backend.

### Login Process

1.  **Navigate to the UI URL:** Open your web browser and go to the URL where the Plandex UI is hosted (e.g., `http://localhost:8081` if running locally, or your deployed Plandex UI address).
2.  **Enter Credentials:** You will be presented with a login screen.
    *   Enter your **Email**.
    *   Enter your **PIN** or **Sign-in Code**.
    *   If using a sign-in code, check the "Use Sign-in Code" box.
    [Screenshot: Login screen with fields for Email, PIN/Sign-in Code, and checkbox]
3.  **Click Login:** After entering your credentials, click the "Login" button.
4.  **Organization Selection:** If your account is associated with multiple organizations, you may be prompted to select one, or one will be chosen by default. You can typically switch between organizations using the organization selector in the navigation bar.
    [Screenshot: Organization selector in the UI navigation bar, if applicable]

Upon successful login, you will be directed to the main dashboard or the default view of the UI Management Interface, granting you access to its various features.

## Main Features

The UI provides several key management areas:

*   **LLM Management:** Configure custom language models and group them into model packs for different tasks.
*   **File Management:** Upload, list, download, and delete files associated with your projects.
*   **Real-time Preview:** A live HTML/CSS/JS sandbox for frontend code experimentation.
*   **Terminal Input:** Execute commands within your project's environment.
*   **Code Interaction:** Utilize LLMs to generate, explain, or modify code within a dedicated editor view.

Navigate through these features using the main sidebar or navigation links within the UI.
